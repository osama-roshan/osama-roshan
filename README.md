## How an AI system works

These two flows show the patterns that I study and practice.

RAG pipeline (RAG means the LLM reads your own documents before it answers):

```text
[ User question ]
        ↓
[ Convert the question to an embedding ]
        ↓
[ Search ChromaDB for similar text ]
        ↓
[ Get the best matching text ]
        ↓
[ LLM reads the text and the question ]
        ↓
[ Answer based on the text ]
```

Agent loop (an agent is an LLM that can use tools):

```text
1. Receive a goal.
2. Plan the next step.
3. Call a tool (an API or an MCP server).
4. Read the result.
5. If the goal is not met, go to step 2.
6. If the goal is met, return the final answer.
```
